# Hydra Water v2

Lightweight Android hydration reminder app.

Features:
- Age, height and weight onboarding
- Personalized starting water estimate
- Saved daily goal and intake with DataStore
- Automatic daily reset
- +250 ml / +500 ml tracking
- Reminder interval selection (1–4 hours)
- Local scheduled notifications
- Material 3 UI
- Android 10+ target for compatibility with older devices

Build:
Open the project in Android Studio and use Build > Build APK(s).
